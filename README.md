# Organize Schedule - Organizador de Estudos

## 📚 Sobre o projeto

O Organize Schedule é uma aplicação web desenvolvida para ajudar estudantes a organizarem tarefas, provas e trabalhos acadêmicos em um único lugar.

## 🎯 Problema resolvido

Muitos alunos esquecem atividades importantes por falta de organização. O sistema centraliza tarefas e facilita o acompanhamento das atividades acadêmicas.

## 👥 Público-alvo

Estudantes que desejam melhorar sua organização de estudos.

## ⚙️ Funcionalidades

* Cadastro de tarefas
* Definição de categoria e prazo
* Marcar tarefas como concluídas
* Remover tarefas
* Filtro de tarefas por categoria e status

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* API

## ▶️ Como executar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
