# Organize Schedule - Organizador de Estudos

## 📚 Sobre o projeto
O Organize Schedule é uma aplicação web criada para ajudar estudantes a organizarem tarefas, provas e trabalhos acadêmicos em um único lugar.

## 🎯 Problema resolvido
Muitos alunos esquecem atividades importantes por falta de organização. O sistema centraliza tarefas e facilita o acompanhamento das atividades acadêmicas.

## 👥 Público-alvo
Estudantes que desejam melhorar sua organização de estudos.

## ⚙️ Funcionalidades
- Cadastro de tarefas
- Definir categoria e prazo
- Marcar tarefas como concluídas
- Remover tarefas
- Filtrar tarefas por categoria e status
- Persistência de dados com localStorage

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- localStorage

## ▶️ Como executar
1. Clone o repositório
2. Abra o arquivo index.html no navegador
